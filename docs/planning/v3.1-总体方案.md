## 0. 设计宪法（验收框架，优先级降序）

1. **科学正确**（不可妥协）：每步自动化有科学门禁；LLM 不进数值链路；证据链可回溯；不实现无把握的功能
2. **产出超越对标**：张洪毅论文产出集（32 图 6 表）是下限；功能面与好用度超越 starpivot-DFT
3. **论文级出图**：所有图默认出版级，无"草稿档"
4. **大通量**：单点是批量的特例
5. **一平台完成**：结构获取→建模→计算→分析→出图→报告不离开软件（研究场景系统裁剪呈现）

## 1. 目标定义：复现并超越对标论文

验收基准 = 张洪毅《单原子催化剂对锂硫电池正极催化机理的第一性原理研究》全部产出：

- **体系**：12 个催化剂表面（10 SAC + Fe@BNC 两位点）× 9 种吸附质（S8/Li2S8~Li2S/*LiS/*LiS2 开壳自由基）+ ~10 个参考体系；68 个最终吸附态
- **计算类型**：弛豫（PBE+D3+自旋，550/500 eV，Γ 3×3×1）、静态（9×9×1，PDOS/ELF/静电势/AECCAR）、频率（ZPE/熵→ΔG）、CI-NEB（Li2S 分解能垒）、AIMD（NVT 300K 10ps）、DFT+U、Bader、LOBSTER/COHP、差分电荷（AB/A/B 三单点）
- **产出**：30 幅自产图（吸附构型拼版/自由能台阶×电位/双支火山/PDOS d-p 杂化/ELF/Bader 标注/COHP/自旋密度/静电势/AIMD 曲线/NEB 能垒）+ 6 张数据表
- **量级**：约 400–700 个 VASP 作业（含构型试探）——这就是"大通量"的实际标定

超越点（示例）：多自旋态并跑（论文未做）、收敛扫描 SI、误差条、不确定度标注、一致性证书、周期性 NCI（critic2）、双语 Methods 自动成段。

## 2. 总体架构（五层）

### 2.1 地基层：campaign 文件式控制面（AICC 采纳蓝图 E1–E8，P0）

服务确定性自动驾驶（现在）与 AI autopilot（未来）的同一层地基，与 AI 解耦：

- `.vcstudio/campaign/<id>/`：YAML 任务节点（依赖/成功判据/required_checks）+ JSONL 账本（decisions/events/artifacts）为唯一事实源；"就绪"为派生量永不落盘
- **三态分离**：completed（作业退出）≠ validated（解析+收敛判据通过）≠ accepted（门禁+人工确认签字）；只有 accepted 进 ΔE/图/报告
- **三门**：submit_gate（机时硬上限+单点先行）/ accept_gate（方法指纹一致性）/ report_gate（图 provenance 完备）；deny-by-default，只卡 release 不卡创作
- **方法指纹对象化**：fingerprint.yaml（泛函/色散/POTCAR 身份/ENCUT/k 策略/自旋 U/参考态/收敛判据），每能量带 hash，一次比较必须同指纹 → 直接产出可复现包"一致性证书"
- **决策账本**：每个自主默认、自愈决定、人工签字 append-only 记录（组会拷问材料/教学模式数据源）
- **机时账本+硬上限闸**：预估 vs 实际核时，触顶即停（自动化的安全带）
- 生产者≠验收者边界、路径安全与密钥红线、轻量单机锁

### 2.2 科学层：46 项功能矩阵（P0 24 项）

完整矩阵见调研归档。**P0 缺口 TOP10（按论文复现阻塞度）**：

1. F18 CI-NEB 全流程 + Li2S 分解模板（需提交模型扩展多 image，最大单体缺口）
2. F14 频率生成端 + ZPE/熵引擎（解析端已有，生成端是 ΔE→论文级 ΔG 第一缺口）
3. F19 PDOS 投影 + d 带中心 + d-p 杂化出版图（机理叙事核心）
4. F20+F21 Bader + 差分电荷全链（顶刊必备，共享静态可一并交付）
5. F22 LOBSTER/COHP 全链 + ICOHP 描述符（含 spilling 质量闸）
6. F1 SAC 基底模板库 + 金属批量替换建模（10 体系入口）
7. F5 吸附位点枚举 + 取向采样（+F4 LiPS 分子库/参考态引擎）
8. F3 多自旋初猜并跑 + 磁矩守卫（自旋误判可致 ΔE 偏差>0.5 eV）
9. F23 描述符统一提取 + 火山图自动构造（标度→包络→顶点全自动）
10. F15 虚频检测分类与自愈（ΔG 质量闸）

小工作量顺带：F8 双弛豫、F24 Eb/Ecoh 稳定性判据、F6 偶极/极性护栏、F10 熵项守卫、F13 色散审计；升级：F16 CHE 通用引擎（物种链+电子数+参比电对，Li-S/ORR/HER/OER/CO2RR 预设）、F17 campaign DAG、F12 参数指纹。P1：位点去重/MLFF 预筛/收敛向导/VASPsol/AIMD/NUPDOWN 扫描等 15 项；P2：GC-DFT/微观动力学等 7 项。

### 2.3 呈现层

- **图表预设库**（四类图谱调研→预设清单）：能量学（台阶×电位/火山/标度/BEP/NEB 剖面）、电子结构（PDOS 镜像/d 带标线/COHP/差分电荷/ELF/自旋密度/静电势/功函数）、结构渲染（构型拼版/键长标注/NEB 快照）、电池专属（16e SRR 全路径/放电台阶/分解能垒对比）。每图型=预设参数+数据契约+provenance 模板，"点选图型→套自己数据→直接进论文"
- **收尾流水线 Draft-Ready**（Fable 创意采纳）：Methods 自动成段（从 provenance 逐字回读+引文兜底，缺项写 [待确认] 绝不编造）、SI 装订机（真实文件搬运装订+续算标注）、三线表工厂（每数可点回证据链）、编号交叉引用管家、口径一致性稽核。AI 不编造，只组织真实数据
- **周期性电子结构可视化**（方向修正）：不对标 Multiwfn 分子 ESP，做周期对应物——critic2（固体 NCI/QTAIM）、LOBSTER、Henkelman Bader、LOCPOT 功函数、CHGCAR 差分/ELF/PARCHG + VESTA 级渲染

### 2.4 入口层

- **结构工坊**：3Dmol.js 交互编辑层（增删/移动/旋转原子、标签、测量；底层 API 已具备，~3-6 人周）+ pymatgen/ASE 后端（切面 SlabGenerator/异质结 CoherentInterfaceBuilder/吸附质摆放/固定底层），合计 2-3 人月覆盖 CatGo 全部功能点
- **模板化候选矩阵**：周期表交互选金属 × 配位环境（N4/N3/P1N3/S1N3/B1N3…对称去重）× 吸附质库 → 作业矩阵；单点先行闸（先跑 1 个代表对文献，再 fan-out）
- **AI 智能体入口**（**用户裁决 2026-07-17：v3.1 做到全自动，推翻评审团"助手层先行"建议**）：论文 PDF → 方法指纹+体系+产出集抽取（每格标出处）→ 实例化 campaign → 自动建作业矩阵 → 自动驾驶跑完 → 出图出报告。落地于 Phase C（依赖 Phase A 控制面 + Phase B 矩阵能力）。**不可拆除的护栏**（宪法第一条对全自动模式一体适用，这些是代码级硬闸不是提示词）：LLM 仍不进数值链路（只做解析与文字解读）；机时硬上限闸+单点先行闸（先跑 1 个代表作业对文献值再 fan-out）；方法指纹一致性硬校验；completed/validated/accepted 三态（AI 无权 accept，验收是确定性检查+可选人工）；矛盾结果熔断（复现值超误差带→停机平铺给人，绝不 spin）；决策账本全程记录可审计可否决；默认交互确认模式，全自动为用户显式开启的开关
- **研究场景系统**（用户提案）：首启选研究方向（锂硫/电催化/热催化/电池材料/分子化学）+ 常做计算 → 声明式场景包决定 界面裁剪/图表预设排序/默认参数与 advisor 规则集/AI 默认上下文/引擎显隐；场景包=社区贡献最小单元

### 2.5 横切：i18n 与文案

先术语统一（"组态"→"构型"全库 87 处、任务/作业统一、决速步→限制电位步(PDS)发刊口径、术语表 15 条），再建字符串字典（~700–1000 条），后英文化（methods_text 双函数模式推广）。总量 4–6 人周。

## 3. 多引擎战略（**用户裁决 2026-07-17：三引擎都要，推翻 PM 建议**）

- **VASP**：主引擎，Phase A/B 深耕（全部科学层 TOP10 在 VASP 上落地）
- **CP2K**：Phase C 接入（开源，AIMD 强项）。CalcSpec IR + Backend 适配器架构在 Phase A 就按引擎无关设计；跨引擎参考态一致性强制校验先行（ENCUT≠CUTOFF、PAW 价≠GTH 价、U 不可盲抄——弹不等价清单逐项确认）
- **Gaussian**：Phase C 接入，定位"分子参考态/溶剂化/分子热化学"（gjf 生成+fchk/log 解析）；同时评估 xtb/ORCA 免费路线作为默认，Gaussian 为用户自有许可时的选项
- **Materials Studio (CASTEP/DMol3)**：Phase C 做**输入生成+输出解析+提交适配**（.cell/.param/.input 文件级适配）。约束条件（法律与工程现实，不可绕过）：软件本体与许可由用户自备，vcstudio 绝不捆绑其任何组件；适配层独立模块，MS 缺席时全无感降级；文档明示"需自有 Materials Studio 许可"
- 每个新引擎上线前必须过"引擎验证债"关：至少一组跨引擎参考体系对拍（同一体系 VASP vs 新引擎能量差与文献一致）才开放给用户——宪法第一条对三引擎一体适用

## 4. 分期实施（v3.1 内三阶段）

- **Phase A 地基+垂直线**（≈4-6 周工程量）：campaign 控制面（E1-E8）+ 科学层 TOP10 中的 F14/F19/F20/F21/F3/F15/F16 + F1/F4/F5 建模入口 + 端到端复现 1 个 SAC 体系 → **MAE 表落进 validation.md**（用户集群真跑）
- **Phase B 大通量+动力学**：候选矩阵（F25 枚举+F28 去重）+ F18 CI-NEB（提交模型扩展）+ F22 COHP + F23 火山自动构造 + 批量自动驾驶矩阵版 → 复现论文全部 12 体系产出
- **Phase C 体验+生态**：结构工坊 + 图表预设库全量 + 收尾流水线 + 场景系统 + AI 助手层 + i18n 英文化 + 开源社区基建（教程/场景包市场/JOSS 投稿）

MVP 验收（Phase A 出口）：新研究生全程不碰终端，导入 SAC 结构→向导四件套→自动驾驶跑完→出版级台阶图/火山图 + 证据链可复现包，至少一个数值 MAE 进 validation.md。

## 5. 不做清单

单分子波函数秀（starpivot 主场；周期性对应物照做）/ 通用工作流引擎与云服务化（AiiDA 地盘）/ 重写已被信任的解析算法（VASPKIT/pymatgen/critic2/LOBSTER 能调用就调用）/ LLM 进数值链路、AI 写 Methods 数字、AI 自主判定收敛（全自动模式下同样禁止）/ 无把握科学功能"支持但可能错" / 捆绑任何商业软件组件（MS 仅做文件级适配）。

## 6. 开源路线

MIT 不变；场景包/图表预设/集群配置库为社区贡献单元；内建论文复现回归基准（10-20 篇 CC-BY 催化论文 fixtures，加权 rubric 禁 LLM 直接给分）持续公开跑分；B 站"一镜到底"演示（mp-id→切 slab→自动驾驶→火山图）对冲 starpivot 的 DECIMER 营销；AGPL/CC-BY-NC 项目（CatGo/AICC）只学思想不抄代码。

## 7. 风险与对策（PM 终审）

1. 科学静默错数随广度放大 → 验证前置闸+每分析带质量闸+广度排验证后
2. 自动化跑在信任前 → AI 只到助手层、机时闸随批量同版、单点先行、决策账本
3. 战略稀释 → 不碰清单硬执行、只在对手结构性进不来的地方发力
