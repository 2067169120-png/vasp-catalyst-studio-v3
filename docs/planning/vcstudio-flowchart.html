二、作业状态机(job.yaml)

stateDiagram-v2
  [*] --> CREATED: 生成四件套
  CREATED --> UPLOADED: SSH 上传
  UPLOADED --> SUBMITTED: qsub/sbatch
  SUBMITTED --> QUEUED: 调度器现身(排队)
  SUBMITTED --> RUNNING: 调度器现身(运行)
  SUBMITTED --> SUBMITTED: 续算沉降(疑在排队)
  QUEUED --> RUNNING
  RUNNING --> DONE: 收敛+能量合理
  RUNNING --> UNCONVERGED: 未收敛(可续算)
  RUNNING --> FAILED: 硬崩/缺输出
  RUNNING --> NEEDS_HUMAN: 规则未命中
  UNCONVERGED --> SUBMITTED: 有界恢复重投(≤3轮)
  DONE --> [*]
  FAILED --> [*]
  NEEDS_HUMAN --> [*]

三不变式:① 方法学主权(用户 INCAR/模板逐字透传)② 确定性核心零 token ③ 显式状态、永不静默(每次变更追加可审计历史)。
