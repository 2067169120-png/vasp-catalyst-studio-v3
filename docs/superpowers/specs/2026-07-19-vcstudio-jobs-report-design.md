## 1. 目标

从整理后的 VASP 计算目录自动构建一份论文叙事型大型比较报告，覆盖 Co、V、Nb、Ta、Zn 和 Zn–Ta 六种催化体系。报告必须包含：

1. 六种催化剂及各 Li–S 中间体的结构图；
2. 六条反应路径叠加在同一张图中的电子能台阶比较；
3. 以 `Eads(Li₂S₂)` 为描述符、以极限电位 `U_L` 为活性指标的火山图；
4. 吸附能、路径能量、PDS、收敛状态和计算设置的可追溯数据表；
5. 一份合并 DOCX、一份定稿 PDF、独立高分辨率 PNG/矢量 PDF 图包和 CSV 数据包。

定量结果必须直接来自当前 VASP 输出文件和软件现有能量计算核心。报告生成过程中不得修改原始数据。

## 4. 总体架构

新增一个独立的“总报告编排器”，直接读取 `vcstudio_jobs\done`，而不是依赖旧的 `results/imported/<group>/project.yaml` 和可能过期的 `job.yaml.state`。

编排器由以下边界清晰的组件组成。

### 4.1 数据发现与清单组件

职责：

- 扫描数据根目录；
- 按规范名称识别六个催化剂、六个吸附态和六个分子参考；
- 忽略但记录 `_old_zbrnt`、`_round2_crashed` 等历史运行目录；
- 为每个目标状态确定唯一、明确的正式输入目录；
- 输出 `data_manifest.csv`。

该组件不读取科学结果，只负责“应该读取哪个目录”和“是否完整”。重复候选、缺失状态或命名冲突必须形成显式错误，不能静默选择。

### 4.2 VASP 结果验收组件

职责：

- 从 OUTCAR/vasprun.xml 中提取最终总能；
- 检查电子与离子收敛标志；
- 提取最终离子步数和最大残余力；
- 从 INCAR/OUTCAR 提取交换关联泛函、ENCUT、色散修正、ISPIN 等关键参数；
- 记录 CONTCAR 是否存在且可解析；
- 输出统一质量状态：`PASS`、`WARNING` 或 `FAIL`。

正式报告生成前重新验收当前磁盘文件，不以目录名 `done` 或旧 YAML 状态作为充分证据。

### 4.3 统一数据模型

每个“催化剂 × 状态”记录至少包含：

- `catalyst`
- `site_type`
- `state`
- `source_dir`
- `energy_e0_ev`
- `converged_electronic`
- `converged_ionic`
- `ionic_steps`
- `max_force_ev_a`
- `quality_status`
- `quality_notes`
- `incar_signature`
- `contcar_path`

派生结果使用独立字段保存：

- `adsorption_energy_ev`
- `relative_path_energy_ev`
- `step_delta_e0_ev`
- `step_delta_e0_per_electron_ev`
- `pds_index`
- `limiting_potential_v`
- `descriptor_eads_li2s2_ev`

报告表、图和 CSV 必须从同一份统一结果对象生成，避免多处重复计算导致数值漂移。

### 4.4 能量计算组件

吸附能采用：

`Eads(X) = E(slab + X) - E(slab) - E(X)`

Li–S 路径、反应计量、逐步电子数、PDS 和 `U_L` 以 `vcstudio.project.freeenergy` 的现有实现为唯一规范来源。总报告层只负责调用和展示，不在新脚本中另写一套不一致的反应公式。

所有路径统一采用节点：

`S₈ → Li₂S₈ → Li₂S₆ → Li₂S₄ → Li₂S₂ → Li₂S`

显示规则：

- 每条路径以 S₈ 起点归零；
- 标题、坐标轴和正文均写明“DFT electronic-energy approximation / DFT 电子能近似”；
- 不将当前 `U_L` 错写成直接相对于 Li/Li⁺ 的绝对电位；
- 若所有体系的 PDS 相同，仍逐体系计算并记录，不从一个体系复制结论。

### 4.5 结构渲染组件

使用仓库中的 POV-Ray 渲染能力直接读取正式 CONTCAR，生成统一视角的俯视图和侧视图。

结构颜色：

| 元素/角色 | 颜色 |
|---|---|
| C | `#8f5b2c` |
| N | `#c6cbe9` |
| S | `#ffd51f` |
| Li | `#9bd58a` |
| 主金属 | `#2b63c9` |
| 双金属第二元素 | `#d8552b` |

渲染规范：

- 白色实底；
- 同一反应物种在六个催化剂上的相机方向、缩放和裁切尽可能一致；
- 每个催化剂/状态生成俯视和侧视图；
- 侧视图只标注与讨论直接相关的关键 `d(S–M)` 距离，避免满图尺寸线；
- 孤立分子参考单独生成结构图；
- POV-Ray 透明输出必须先合成白底，防止 Word/PDF 中出现黑块。

### 4.6 图表组件

#### 固定催化剂颜色

| 催化剂 | 颜色 | 辅助识别 |
|---|---|---|
| Co | `#2a78d6` | 固定标记形状 |
| V | `#1baf7a` | 固定标记形状 |
| Nb | `#eda100` | 固定标记形状和直接标签 |
| Ta | `#008300` | 固定标记形状 |
| Zn | `#4a3aa7` | 空心标记、`⚠` 和脚注 |
| Zn–Ta | `#e34948` | 固定标记形状 |

该六色顺序已经通过数据可视化调色板验证。浅色系列必须配合图例、直接标签和标记形状，不能只依赖颜色。颜色始终跟随催化剂，不随排序改变。

#### 吸附能

- 主视图使用“中间体 × 催化剂”热图，适合比较二维数值矩阵；
- 采用单一连续色相或以零为中点的蓝–灰–红发散色标，具体取决于数据范围和分析目的；
- 配套提供精确数值表；
- 需要强调某一中间体时使用单独排序图，不在一张图中堆叠过多标签。

#### 统一台阶能图

- 一张主图同时包含六条完整路径；
- 2 px 台阶线、圆角连接、细实线网格；
- 图例始终存在；
- 端点可直接标注催化剂名称，节点数值不全部堆到主图上；
- 每条路径的 PDS 使用外圈、箭头或局部强调；
- Zn 使用空心标记和警示注释；
- 主报告另附六张小型单体系台阶图，用于读取逐步变化；
- 不使用双 Y 轴。

#### 火山图

- 横轴：`Eads(Li₂S₂) / eV`；
- 纵轴：`U_L / V`；
- 六个散点全部直接标注名称；
- Zn 使用空心点和警示；
- 趋势曲线使用中性灰色，仅作为视觉引导；
- 正文采用“描述符相关趋势”措辞；
- 图下同步提供 `Eads(Li₂S₂)`、PDS、`U_L` 和质量状态表；
- 不报告缺乏样本支持的强统计结论。

所有静态图输出 300–600 dpi PNG 和矢量 PDF。图中文字、图例、轴标签和上下标必须在 DOCX 与 PDF 中保持清晰。

### 4.7 报告组装组件

主报告采用以下论文叙事结构：

1. 封面与执行摘要；
2. 数据集与计算方法；
3. 数据质量与可比性；
4. 催化位点与吸附构型总览；
5. 吸附能比较；
6. 六体系统一台阶能比较；
7. 极限电位与火山关系；
8. 逐催化剂结果讨论；
9. 综合结论与后续建议；
10. 全结构和全数据附录。

正文结构图安排：

- 六种裸基底并排；
- 对 S₈、Li₂S₈、Li₂S₆、Li₂S₄、Li₂S₂、Li₂S 分别制作六催化剂俯视对比页；
- Li₂S₂ 和 Li₂S 增加侧视图和关键距离；
- 附录收入 42 套基底/吸附结构的俯视与侧视图，以及 6 个孤立分子参考图。

报告正文为中文；图题、坐标轴和图注提供中英文。定量讨论使用规则驱动模板和已计算统计值，不允许生成式文本改变数值或把警告写成结论。

### 4.8 导出组件

## 6. 异常处理

### 6.1 不允许静默跳过

以下情况必须显示在清单并影响最终状态：

- 缺少目标状态；
- OUTCAR/CONTCAR 不可读；
- 同一状态存在多个未明确优先级的候选；
- 总能无法解析；
- 计算设置不一致；
- 离子或电子未收敛；
- 结构渲染失败；
- DOCX 或 PDF 导出失败；
- 图、表和 CSV 数值不一致。

### 6.2 状态规则

- `PASS`：输入完整、结果可解析并满足既定收敛要求；
- `WARNING`：结果可用于用户明确要求的探索性比较，但存在必须披露的问题；
- `FAIL`：缺失或解析错误使定量结果不可信。

Zn 的最终状态由当前 OUTCAR 复核决定。若 `Zn_S8` 仍未达到目标残余力或离子收敛标准，则 Zn 为 `WARNING`，但根据用户决定继续进入全部主图和拟合。

### 6.3 原始数据保护

- `vcstudio_jobs\done` 只读；
- 不移动、重命名、覆盖或删除任何源文件；
- 所有中间文件和最终交付物只写入新的 `report_output` 目录；
- 历史运行目录只审计、不修改。
