## 为什么采用轻量融合

MatClaw 是面向独立 Agent 运行环境的完整系统；其 Node.js、容器和模型 SDK 选择适合
自身部署目标。vcstudio 的核心目标则是可冻结为 Windows 单文件程序，并复用已经接受
科学门禁、输入哈希、集群白名单和有界续算约束的 Python 计算链。因此这里不把另一套
执行栈塞进桌面程序，也不让聊天层绕过现有后端。

| MatClaw 中值得借鉴的概念 | vcstudio 的 Python 原生落点 | 明确不引入 |
|---|---|---|
| 可恢复会话与消息历史 | 本地会话、消息和时间线；重新打开后可继续 | Node.js 20 服务 |
| 多文件附件 | 每会话隔离的附件工作区、流式 SHA256、类型与配额检查 | Docker/容器编排 |
| `/status` 与任务事件 | 对现有项目和自动托管状态的只读摘要 | Claude Agent SDK 或 Codex SDK |
| `/stop` | 只停止当前 AI 响应，不触碰计算作业 | 任意 shell 执行 |
| 技能/工具路由 | 显式白名单命令调用现有 Python API | 绕过门禁的自由代码执行 |
| 会话恢复 | 恢复聊天上下文和本地附件索引 | 隐式恢复或重提集群作业 |

## 信任边界

### 1. AI 层不进入数值事实链

- DFT 能量、收敛状态、吸附能、自由能、PDS 和限制电位均由确定性解析器计算。
- AI 可以解释已有结果、整理方法或建议下一步，但不能把模型文本写成
  `accepted` 数值事实，也不能伪造缺失的计算证据。
- 报告中的关键数字继续绑定输入、输出、代次和文件哈希；聊天记录不是科学证据。

### 2. 文件上传先落入会话沙箱

- 附件复制到当前会话的独立工作区，不直接覆盖项目源目录。
- 复制过程流式计算 SHA256，并限制单文件大小、会话总量和允许的预览格式。
- ZIP 必须拒绝绝对路径、`..` 穿越、符号链接逃逸、异常压缩比和超额解压体积。
- 二进制或未知格式只登记元数据，不作为文本塞进模型上下文。
- 用户文件默认在本地解析；启用外部模型时，只发送完成请求所必需的摘要和明确选择的内容。

### 3. 聊天命令采用最小权限

对话入口只暴露经过审计的白名单能力。例如：

- `/help`：显示可用命令和安全说明。
- `/status`：只读查看项目、成员、续算轮次、下一次检查和报告状态。
- `/report`：调用现有本地报告门；门禁不通过时只能生成诊断报告。
- `/stop`：取消当前 AI 生成任务。

`/stop` **不是**集群取消命令。取消 PBS/Slurm 作业、重新提交、续算、覆盖源文件或
修改远端目录仍必须走原有显式操作、服务器归属校验和确认流程。对话内容不会被拼接成
shell 命令，也不会获得通用终端、任意 Python 或远端命令执行能力。

### 4. 自动托管仍由确定性主管负责

聊天界面可以读取自动托管状态，但不能取代主管线程。监控、下载、诊断、最多三轮续算
和完成后报告由应用内 Python 主管按保存的项目/作业白名单调度。主管随应用进程运行；
本文不宣称关闭程序后继续执行，也不宣称系统托盘或操作系统服务能力。

## 数据流

1. 用户新建或恢复一个本地会话。
2. 用户选择附件；安全导入器复制、限额检查并记录哈希。
3. 本地解析器生成有限的文本摘要或结构化元数据。
4. 路由器区分普通问答与显式白名单命令。
5. 只读命令从现有项目/主管状态读取；报告命令仍通过报告门。
6. 外部模型（若启用）只接收必要上下文；响应以普通消息保存，不写入计算事实文件。
7. 用户可停止 AI 响应；正在运行或排队的 HPC 作业保持不变。

## 部署与依赖原则

- 不新增 Node、npm、Docker、容器守护进程或 MatClaw 数据库服务。
- 不绑定某一家模型 SDK；模型连接使用 vcstudio 已有、可替换的接口和凭据存储。
- 离线或未配置模型时，项目状态、附件管理、确定性分析与报告功能仍可工作。
- 冻结版只收录本项目实际使用的 Python 依赖；上游 MatClaw 不作为运行依赖。

## 维护检查清单

对话助手相关改动合并前至少验证：

- 会话之间不能读取彼此的附件。
- 路径穿越、符号链接和压缩炸弹样例均被拒绝。
- `/stop` 不调用任何集群取消、删除或续算入口。
- `/status` 不泄露凭据、完整密钥、远端私有路径或不属于当前项目的数据。
- 模型不可用或响应中断时，本地消息与附件索引仍保持一致。
- 报告命令沿用正式/诊断报告门，AI 文本不能把诊断报告升级成最终报告。
- 所有新增外部代码都重新执行许可证与 NOTICE 审计；“设计参考”不能替代许可证义务。
