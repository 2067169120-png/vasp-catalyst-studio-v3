② 规格表(可编辑;每格显示值 + 出处 + 低置信度黄标)
③ 实例化计划
全自动仍受硬护栏约束:机时上限 + 单点先行(pilot 先跑通)+ 三态门禁(completed→validated→accepted); 且需先在设置页允许项目数据外发。计算值与文献锚点偏差超阈值将「科学停」平铺呈报,绝不自动判复现成功。
数据对照(文献值 × 计算值)
从上方论文提取文献数据表(体系×物种×文献值,带页码);项目算完后与计算值对照给 MAE/RMSE。抽出的是文献参考值,仅供对照,绝不回流计算。
材料变体(母版 → 邻域筛选)
据规格表母版体系推荐变体(金属替换 / 配位调控 / 掺杂),排除论文已算过的组合;按优先级 + 机时预算分批。
论文草稿(骨架 + Methods 全自动)
Methods 用真实 INCAR 全自动;Results 逐图数据句 + 占位待补。诚实展示 AI 组织了多少、留给你多少。
