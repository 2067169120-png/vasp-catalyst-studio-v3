# 待处理归档 (quarantine)

本目录存放**过程性文件**——阶段性笔记、一次性完成报告等非长期资产。
移入此处只为清理根目录,**绝不删除**;等用户逐条定夺(保留/移回/删除)。

## 清单

| 原路径 | 为何判定为过程性 | 建议 |
|---|---|---|
| `docs/2026-07-05-夜间优化完成报告.md` | 某夜间自动优化的一次性完成报告,内容已并入 git 历史与后续文档,非长期维护文档 | 确认无用后删除 |
| `继续开发-交接总结.md`(原根目录,未跟踪) | 过期会话交接笔记,当初已故意不入库(见 progress.md);仅供人工回顾 | 确认后删除 |

## 约定

- 移入用 `git mv`(已跟踪文件)或普通 `mv`(未跟踪文件);未跟踪文件移入后仍保持未跟踪。
- 保护线:`vcstudio/`、`results/`、`dist/`、`tests/`、`docs/superpowers/` 内容不进本目录。
- 如需恢复某文件,移回原路径即可(git mv 的文件有历史可查)。
